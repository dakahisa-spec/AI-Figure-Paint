# AI Figure Paint Gift v0.8.2

레진피규어와 프라모델의 보유 도료, 도색 프로젝트, 조색 레시피를 관리하고 AI 조색 보조를 제공하는 Android 앱입니다.

## 포함 기능

- Room 최초 생성 시 제품 목록은 유지하되 보유 상태는 0개로 시작
- 도료 검색, 브랜드/보유/즐겨찾기/최근 사용 필터, 단계형 잔량 관리
- 도료 병·라벨 직접 촬영 또는 갤러리 선택 후 GPT-5.6으로 브랜드·코드·제품명·대표색 초안 생성
- 프로젝트 사진 직접 촬영 또는 갤러리 선택 후 GPT-5.6으로 프로젝트명·모델명·시작일 후보·진행 상태·작업 메모 초안 생성
- 프로젝트와 레시피의 관계형 연결, 사진, 작업 Timeline
- 조색 레시피 버전 기록과 목표 총량(3/5/10/15/20ml) 자동 환산
- 보유 도료를 우선하는 AI 조색 생성·수정 및 프로젝트 도색 상담
- 사진 확대/이동/십자선 선택과 9×9 평균 RGB·HEX 로컬 분석
- AI 미연결 시에도 작동하는 로컬 색상 거리 기반 후보
- 밝은 아이보리·화이트·로즈 포인트 기반 Material 3 테마와 Fold7 커버/펼침 반응형 UI
- 카메라 권한, FileProvider, 접기·펼치기 상태 보존을 지원하는 도료·프로젝트 촬영 등록
- 모든 사용자 데이터는 기기 내 Room DB에 저장

## AI 연결과 비밀값

AI 기능은 GPT-5.6을 사용합니다. API 키는 소스, Gradle 설정 또는 APK 상수에 포함하지 않습니다. 앱의 `AI 연결 설정`에서 입력한 값은 Android Keystore로 보호해 기기 안에 저장합니다. 배포용 상용 빌드에서는 사용자의 API 키를 앱에 보관하는 대신 서버 측 프록시를 사용하는 구성이 권장됩니다. API 키가 없어도 도료·프로젝트·레시피·총량 환산·사진 색상 추출·로컬 추천은 정상 작동합니다. 도료 및 프로젝트 사진 분석 결과는 검토용 초안이며 사용자가 확인 후 저장해야 DB에 반영됩니다.

## 기술 스택

- Kotlin 2.1.20 / Android Gradle Plugin 8.9.2
- Jetpack Compose / Material 3
- Room 2.7.2
- minSdk 26 / targetSdk 34

## 빌드

JDK 17과 Android SDK 34 환경에서 `gradle assembleDebug`를 실행합니다.

생성 경로:

`app/build/outputs/apk/debug/app-debug.apk`

Room DB는 1→2→3 Migration을 사용하며 destructive migration을 사용하지 않습니다.
